# State by State — isolated visual study

Open `index.html` locally or serve this folder using `python -m http.server 8000`. The page reads no external data. Its interactive LIS playground implements a **separate in-browser explanation**, not an execution or validation of any C++ file. The default sample sequence is copied from `Class- Longest increasing SubSequence` in the repository; other project filenames and algorithms were inspected for the supporting section. The source repository contains C++ practice snippets, not a packaged library or hosted API.

Visual direction: playful educational staircase, sand + dark teal + aqua + orange, Space Grotesk / DM Sans / Space Mono, hard-edged states, algorithm steps as spatial components. External fonts are optional; fallbacks provided. The `showcase-design` directory is additive only.

Screenshots: `assets/screenshots/desktop.png`, `assets/screenshots/tablet.png`, `assets/screenshots/mobile.png` are real rendered full-page captures. The repository includes a filename with an asterisk, which cannot be checked out by Windows Git; the branch is created from the recorded `main` SHA via the GitHub API instead of renaming any original file.
